## 🤖 Android端实现

### 1. Android插件主类 (ScreenProtectorModule.java)

```java
package io.dcloud.uniplugin;

import android.app.Activity;
import android.view.WindowManager;
import com.alibaba.fastjson.JSONObject;
import io.dcloud.feature.uniapp.annotation.UniJSMethod;
import io.dcloud.feature.uniapp.bridge.UniJSCallback;
import io.dcloud.feature.uniapp.common.UniModule;

public class ScreenProtectorModule extends UniModule {
    
    /**
     * 启用防录屏保护
     */
    @UniJSMethod(uiThread = true)
    public void enableProtection(UniJSCallback callback) {
        try {
            Activity activity = mUniSDKInstance.getContext();
            if (activity != null) {
                // 设置FLAG_SECURE标志，阻止截屏和录屏
                activity.getWindow().setFlags(
                    WindowManager.LayoutParams.FLAG_SECURE,
                    WindowManager.LayoutParams.FLAG_SECURE
                );
                
                JSONObject result = new JSONObject();
                result.put("success", true);
                result.put("message", "防录屏保护已启用");
                callback.invoke(result);
            }
        } catch (Exception e) {
            JSONObject result = new JSONObject();
            result.put("success", false);
            result.put("message", "启用失败: " + e.getMessage());
            callback.invoke(result);
        }
    }
    
    /**
     * 禁用防录屏保护
     */
    @UniJSMethod(uiThread = true)
    public void disableProtection(UniJSCallback callback) {
        try {
            Activity activity = mUniSDKInstance.getContext();
            if (activity != null) {
                // 清除FLAG_SECURE标志
                activity.getWindow().clearFlags(
                    WindowManager.LayoutParams.FLAG_SECURE
                );
                
                JSONObject result = new JSONObject();
                result.put("success", true);
                result.put("message", "防录屏保护已禁用");
                callback.invoke(result);
            }
        } catch (Exception e) {
            JSONObject result = new JSONObject();
            result.put("success", false);
            result.put("message", "禁用失败: " + e.getMessage());
            callback.invoke(result);
        }
    }
    
    /**
     * 检查是否支持防录屏
     */
    @UniJSMethod
    public void isSupported(UniJSCallback callback) {
        JSONObject result = new JSONObject();
        result.put("success", true);
        result.put("supported", true);
        result.put("platform", "android");
        callback.invoke(result);
    }
}
```

### 2. iOS插件实现 (ScreenProtectorModule.m)

```objc
#import "ScreenProtectorModule.h"
#import <UIKit/UIKit.h>

@implementation ScreenProtectorModule

/**
 * 启用防录屏保护
 */
- (void)enableProtection:(UniModuleKeepAliveCallback)callback {
    // iOS的防录屏主要通过监听实现
    [[NSNotificationCenter defaultCenter] addObserver:self
                                             selector:@selector(screenRecordingChanged)
                                                 name:UIScreenCapturedDidChangeNotification
                                               object:nil];
    
    [[NSNotificationCenter defaultCenter] addObserver:self
                                             selector:@selector(userDidTakeScreenshot)
                                                 name:UIApplicationUserDidTakeScreenshotNotification
                                               object:nil];
    
    NSDictionary *result = @{
        @"success": @YES,
        @"message": @"iOS防录屏监听已启用"
    };
    callback(result, NO);
}

/**
 * 禁用防录屏保护
 */
- (void)disableProtection:(UniModuleKeepAliveCallback)callback {
    [[NSNotificationCenter defaultCenter] removeObserver:self];
    
    NSDictionary *result = @{
        @"success": @YES,
        @"message": @"iOS防录屏监听已禁用"
    };
    callback(result, NO);
}

/**
 * 检查是否支持
 */
- (void)isSupported:(UniModuleKeepAliveCallback)callback {
    NSDictionary *result = @{
        @"success": @YES,
        @"supported": @YES,
        @"platform": @"ios"
    };
    callback(result, NO);
}

/**
 * 录屏状态改变
 */
- (void)screenRecordingChanged {
    if ([UIScreen mainScreen].isCaptured) {
        // 检测到录屏
        [self fireGlobalEvent:@"screenRecordingDetected" params:@{
            @"type": @"recording",
            @"timestamp": @([[NSDate date] timeIntervalSince1970] * 1000)
        }];
    }
}

/**
 * 检测到截屏
 */
- (void)userDidTakeScreenshot {
    [self fireGlobalEvent:@"screenshotDetected" params:@{
        @"type": @"screenshot",
        @"timestamp": @([[NSDate date] timeIntervalSince1970] * 1000)
    }];
}

@end
```

## 📱 使用方式

### 启用防录屏
```javascript
import mobileScreenProtector from '@/utils/mobile-screen-protector.js'

// 启用防录屏
mobileScreenProtector.enable()

// 监听截屏事件
mobileScreenProtector.on('onScreenshotDetected', (data) => {
  console.log('检测到截屏:', data)
})

// 监听录屏事件
mobileScreenProtector.on('onRecordingDetected', (data) => {
  console.log('检测到录屏:', data)
})
```

## 🔍 测试方法

### Android测试
1. 打包成APK安装到手机
2. 尝试截屏 - 应该显示黑屏或提示无法截屏
3. 尝试录屏 - 应该显示黑屏
4. 查看最近任务 - 应该显示黑屏

### iOS测试
1. 打包成IPA安装到手机
2. 尝试截屏 - 会触发检测事件
3. 尝试录屏 - 会触发检测事件
4. 检查控制台日志确认事件触发

## ⚠️ 注意事项

1. **Android**: FLAG_SECURE是最有效的防录屏方案
2. **iOS**: 只能检测不能完全阻止，需要配合其他手段
3. **测试环境**: 必须在真机上测试，模拟器可能无效
4. **权限**: 确保应用有必要的权限
5. **兼容性**: 不同Android版本效果可能有差异
