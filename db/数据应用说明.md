## 🔧 数据操作接口

### 📖 **读取数据**
```javascript
// 从user.json读取数据
import users from '@/data/users.js';

// 获取当前登录用户
const currentUser = users.find(user => user.isLoggedIn === true);

// 获取用户特定数据
const userBalance = currentUser.balance;
const transferRecords = currentUser.transferRecords;
```

### ✏️ **更新数据**
```javascript
// 更新用户数据
const updateUserData = (userId, newData) => {
  const userIndex = users.findIndex(user => user.id === userId);
  if (userIndex !== -1) {
    users[userIndex] = { ...users[userIndex], ...newData };
    // 保存到本地存储
    uni.setStorageSync('users', users);
  }
};
```

### 💾 **数据持久化**
```javascript
// 保存数据到本地存储
uni.setStorageSync('users', users);

// 从本地存储读取数据
const storedUsers = uni.getStorageSync('users');
```

## 🛡️ 数据安全

### 🔐 **敏感数据保护**
- **密码加密**: 登录密码和交易密码需要加密存储
- **身份证脱敏**: 身份证号部分位数脱敏显示
- **本地存储**: 敏感数据仅存储在本地，不上传服务器

### 🔒 **数据验证**
- **格式验证**: 手机号、身份证号格式验证
- **数据完整性**: 确保必要字段不为空
- **类型检查**: 确保数据类型正确
